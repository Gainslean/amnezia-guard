# AmneziaGuard — трафик только через AmneziaVPN

[English](README.md) · **Русский**

Kill switch для macOS: если соединение идёт **не через туннель Amnezia**, пакеты никуда не уходят.
Значок-щит в строке меню показывает состояние и скорость.

## Установка

```bash
cd AmneziaGuard
sudo ./install.sh
```

Лучше ставить, **когда Amnezia подключена**: служба сразу запомнит IP вашего сервера.

## Значок в строке меню

| Значок | Что значит |
|---|---|
| 🟢 щит с замком `↓1.3M ↑81K` | Всё в порядке: трафик идёт только через Amnezia, справа скорость |
| 🟠 щит перечёркнут `нет VPN` | VPN отключён, интернет **закрыт**, утечек нет |
| 🔴 щит с `!` `ВЫКЛ` | Правило выключено, трафик может идти мимо VPN |
| 🔴 щит с `×` `?` | Служба не отвечает |

В меню: график скорости за 90 секунд, трафик с момента запуска, туннель и сервер, сколько пакетов
заблокировано мимо VPN, проверка «утечек нет».

## Кнопки выключения

Сразу под статусом:

- **Выключить «только через Amnezia»** — выключает правило, пока вы не включите его обратно той же кнопкой.
- **Выключить на 15 минут** — потом защита включится сама. Таймер ведёт служба, поэтому он сработает,
  даже если значок закрыт.
- Когда правило выключено, на этом месте кнопка **Включить «только через Amnezia»**.

macOS спросит пароль или Touch ID: снять защиту может только администратор.

Из терминала:

```bash
sudo "/Library/Application Support/AmneziaGuard/agctl" off
```

```bash
sudo "/Library/Application Support/AmneziaGuard/agctl" off 15
```

```bash
sudo "/Library/Application Support/AmneziaGuard/agctl" on
```

## Как это работает

- **Служба** (`guard.sh`, root, LaunchDaemon) находит процесс Amnezia и её туннель (`utunN`)
  и загружает правила в брандмауэр macOS (pf, якорь `com.apple/000.AmneziaGuard`).
  Сама блокировка работает в ядре и мгновенна: каждый пакет проверяется за микросекунды.
- **Сторож** (`agwatch`, нативный) слушает события сети ядра и будит службу за миллисекунды,
  когда Amnezia подключается или отключается, меняется туннель или Wi-Fi. Каждые 0,2 с он
  проверяет брандмауэр: если кто-то выключил pf или снял правила, он сам возвращает их
  (на практике за 15–180 мс). Нагрузка около 2% одного ядра.
- Пропускается только: туннель Amnezia, зашифрованные пакеты самой Amnezia к серверу (её UDP-порт
  и запомненные IP серверов), DHCP и, по настройке, локальная сеть. Всё остальное отбрасывается.
- Если служба упадёт, правила **остаются**: интернет закрыт, а не открыт.
- Если кто-то выключит pf (например, другой VPN), сторож включит его обратно за доли секунды.
- Пропускается только туннель самой Amnezia. Другой VPN через правило не пройдёт.

## Настройки

Файл `/Library/Application Support/AmneziaGuard/config`, правится через `sudo nano`, применяется за 2 секунды.

- `ALLOW_LAN=1`: локальная сеть разрешена (принтер, AirDrop, NAS), но DNS роутера закрыт, чтобы запросы
  не утекали провайдеру. `0` закрывает и её.
- `ALLOW_SPLIT=0`: строгий режим. Если в Amnezia настроены исключения (сайты, которые идут мимо VPN),
  в строгом режиме они **перестанут открываться**. Если они нужны, поставьте `1`: служба сама выучит
  их из маршрутов Amnezia.
- `EXTRA_ALLOW="1.2.3.4"`: добавить IP сервера вручную, если сервер сменился при включённой защите.

## Удаление

```bash
sudo ./uninstall.sh
```

Снимает правила и удаляет всё: службу, приложение и настройки.

## Файлы

- `daemon/guard.sh`: служба. `daemon/rules.sh`: правила pf. `daemon/agctl`: управление.
- `tools/agwatch.swift`: сторож событий сети и брандмауэра.
- `app/*.swift`: приложение строки меню. `tools/make_icon.swift`: иконка. `build.sh`: сборка.
